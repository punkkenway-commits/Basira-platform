Von Mises Triaxial Criterion

Consistent with API TR 5C3. Under thin-wall assumption (t/d ≤ 0.10), the equivalent stress reduces to:

σ_eq = √(σ_θ² + σ_z² − σ_θ · σ_z)

Design: σ_eq ≤ σ_allow = σ_y / DF

Burst Load (Hoop Stress)

Worst-case gas-kick internal pressurisation scenario. Maximum load at surface:

σ_θ(burst) = [Pi(D) − Po(D)] × d_i / (2t)

Collapse Differential Pressure

Full mud column external, gas-evacuated internal worst case:

ΔP_collapse = ρ_mud × g × D − P_internal(D)

Directional Bending Stress

Superimposed on axial load at dogleg zone for directional wells:

σ_bend = E × d_o / (2R)
R = 1719.1 / BUR [metres]
E = 206 GPa for steel

HTHP Yield Derating

Applied above BHT ~120°C per API TR 5C3. At 171°C, f_T ≈ 0.96:

σ_y,eff = f_T × σ_y,nominal
σ_allow = σ_y,eff / DF

NACE MR0175 / ISO 15156

H₂S ≥ 50 ppm activates sour service Class 0A. Restricts grade list to SSC-resistant materials with hardness ≤ 22 HRC:

Compliant: L80-SS · C90 · T95
Excluded (Class 0A): Q125*
* Without special qualification

Tier Assignment Hierarchy

Highest-priority trigger governs. No lower-tier criterion can override an adverse higher-priority trigger:

1. H₂S ≥ 50 ppm → DF = 2.0
2. BHT ≥ 150°C or BHP ≥ 69 MPa → DF = 2.0
3. Water Depth ≥ 300 m → DF = 2.0
4. BUR ≥ 3°/30m → DF = 1.6
5. MD/TVD > 2.0 → DF = 2.0
6. Standard vertical sweet → DF = 1.25

Material Selection Logic

Deterministic API 5CT grade selection. NACE constraint is primary hard filter; structural adequacy and cost govern within the compliant set:

Grade priority: J55 → K55 → N80 → L80
→ L80-SS → C90 → T95 → P110 → Q125
Sour filter applied before DF check

Axial Tension (Buoyancy)

Buoyancy-corrected string weight, with bending and thermal contributions:

F_z(D) = W_air × (1 − ρ_fluid/ρ_steel)
+ F_bend + F_thermal
ρ_steel = 7,840 kg/m³

ABOUT

About the Basira Platform

Research Background

Basira implements a five-tier adaptive design factor framework for oil & gas casing design. Published in Geoenergy Science and Engineering (Elsevier, Scopus Q1) by Abdulwadod Mohammed Sabri, Ministry of Oil — submitted March 2026.

Platform Scope

Designed for pre-drill static stress analysis: onshore vertical and moderately deviated wells, and offshore development wells at moderate water depths where APB and torque-drag are not the dominant design drivers.

Standards Referenced

API TR 5C3 — Von Mises stress & pressure calculations
API 5CT — Casing grade specifications
NACE MR0175 / ISO 15156 — Sour service materials
NORSOK D-010 — Well integrity criteria
